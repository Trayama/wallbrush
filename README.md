# WallBrush 0.1.6 GitHub Pages 诊断版

This branch is intended to be served by GitHub Pages, not jsDelivr.

Manifest URL after enabling GitHub Pages:
https://trayama.github.io/wallbrush/manifest.json

GitHub repository Settings > Pages > Build and deployment:
- Source: Deploy from a branch
- Branch: gh-pages
- Folder: /(root)

Save and wait for GitHub Pages deployment. Then open:
https://trayama.github.io/wallbrush/diagnostic.html

Expected: the HTML page is rendered, not shown as source code.
