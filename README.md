# WallBrush（墙壁编辑器）0.1.3

## UI 注册（0.1.3）

- SDK 的 OBR.onReady 触发后立即注册 Tool、Tool Mode、Tool Action，不再等待 Scene Ready。
- 主工具图标位于右侧竖向工具栏；工具栏在场景打开且 Ready 后由 Owlbear 显示。
- 点击主图标后，顶部菜单左侧为绘制墙壁和橡皮擦，右侧为显示/隐藏辅助线和网格吸附。
- 为排查角色过滤导致的隐藏，0.1.3 暂时不对工具图标和模式应用 GM role filter；玩家点击或操作时由 canEditWalls() 拒绝编辑。
- 成功注册后立即弹出「墙壁编辑器 UI 已注册」通知；没有该通知表示后台脚本或 SDK 初始化没有完成。

## 使用

1. 安装并启用扩展，进入一个场景。
2. 在右侧工具栏找到红色斜线方框图标。
3. 点击图标；顶部菜单左侧选择绘制或橡皮擦。
4. 绘制模式下按住鼠标拖动，完成一段墙；转角分段绘制。
5. 橡皮擦模式下点击 DM 本地红色辅助线删除墙段。
6. 顶部右侧动作可隐藏/显示 DM 本地辅助线或切换网格吸附。

## 可见性与碰撞

- 墙壁源数据是隐藏的共享场景线段。
- 只有 GM 本地生成红色墙线辅助；玩家不会看到辅助线。
- 每个客户端从共享源数据生成本地 Wall 对象。
- Wall 使用 blocking=true 和 doubleSided=true。
- 角色已有附着光源时复用；否则尝试生成 SECONDARY 辅助光源作为碰撞锚点。
- 动态视野遮挡需要 Dynamic Fog 或其他提供角色视野光源的扩展。
