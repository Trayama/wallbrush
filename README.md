# WallBrush（墙壁编辑器）0.1.1

Owlbear Rodeo 扩展：DM 绘制墙壁，玩家自动同步本地碰撞墙。

## 安装地址

https://cdn.jsdelivr.net/gh/Trayama/wallbrush@main/manifest.json

## 使用

1. 在 Owlbear 扩展管理中安装并启用 WallBrush。
2. 进入房间后，右侧工具栏应出现「墙壁编辑器」。
3. 选择墙壁编辑器，默认进入绘制模式。
4. 按住鼠标拖动绘制一段墙；拐角处分段绘制。
5. 切换橡皮擦模式，点击红色辅助线删除墙段。
6. 网格吸附默认开启，可通过工具动作切换。
7. 「显示/隐藏 DM 墙线辅助」只影响 DM 自己看到的红色辅助线，不影响碰撞。

## 玩家可见性与碰撞

- 墙线源数据以 visible=false 的共享场景线段保存，普通玩家看不到红色辅助线。
- DM 客户端额外生成本地红色辅助线，只有 DM 自己看得到。
- 每个参与者的客户端根据隐藏源数据生成本地 Owlbear Wall 对象。
- 墙壁使用 blocking=true 与 doubleSided=true，用于阻挡棋子碰撞和双向光影。
- 对没有附着光源的棋子，插件生成 SECONDARY 辅助光源作为碰撞锚点；SECONDARY 不会独立揭开未探索区域。
- 如果棋子已有其他扩展提供的附着光源，则复用现有光源，不额外生成辅助光源。

## 视野说明

WallBrush 负责墙壁几何与碰撞。要看到动态视野被墙壁遮挡，场景还需要一个提供角色视野光源的系统，例如 Owlbear Dynamic Fog 或 Smoke & Spectre。WallBrush 不会自行给角色开放一整套视野规则。

## 多人和托管

不需要自建游戏服务器。墙壁源数据由 Owlbear 场景同步；每位玩家本地生成碰撞墙。插件静态文件托管在 GitHub/jsDelivr。
