# WallBrush（墙壁编辑器）0.1.2

## UI 位置

- 墙壁编辑器主图标：右侧竖向工具栏底部的红色斜线方框图标；只对 GM 显示。
- 点击主图标后，顶部工具菜单左侧出现两个模式：绘制墙壁、橡皮擦。
- 顶部工具菜单右侧出现两个动作：显示/隐藏 DM 墙线辅助、切换网格吸附。
- 工具栏只在打开场景并且场景 ready 后出现；插件会在场景 ready 时注册工具。

## 使用

1. 安装并启用扩展，进入一个已加载的场景。
2. 在右侧竖向工具栏底部找到红色斜线方框图标「墙壁编辑器」。
3. 点击图标；顶部菜单左侧选择绘制或橡皮擦。
4. 绘制模式下按住鼠标拖动，完成一段墙；转角分段绘制。
5. 橡皮擦模式下点击红色辅助线删除墙段。
6. 顶部右侧动作可隐藏/显示 DM 本地辅助线或切换网格吸附。

## 可见性与碰撞

- 墙壁源数据是隐藏的共享场景线段。
- 只有 GM 本地生成红色墙线辅助；玩家不会看到辅助线。
- 每个客户端从共享源数据生成本地 Wall 对象。
- Wall 使用 blocking=true 和 doubleSided=true。
- 角色已有附着光源时复用；否则尝试生成 SECONDARY 辅助光源作为碰撞锚点。
- 动态视野遮挡需要 Dynamic Fog 或其他提供角色视野光源的扩展。
